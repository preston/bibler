POST Scripture search

{{biblerService.getUrl()}}/bibles/:bibleUuid/search

Send a JSON object with a text property. Search returns up to 100 matching verses.

{{'{'}} "text": "jesus christ" {{'}'}}

REST endpoints use UUID identifiers, camelCase JSON properties, and JSON responses. Authenticated application endpoints accept an Authorization: Bearer <token> header.
